## 二、第一阶段目标

完成一个可以离线运行、可复现的小闭环：

`名单的时间可得性 → 身份及股票类别处理 → 近期强弱排名 → 行业约束/保留/补位 → 下一 session 开盘模拟成交 → 账户/拆股/现金分红 → VOO 基准与报告`。

使用明确标为 synthetic 的小数据，验证工程流程，不宣称得到真实 VOO 回测或任何盈利结论。

本阶段不联网，不调用 OpenD，不导入交易 SDK，不读取账户或下单，不安装庞大框架。

## 三、不能改变的研究边界

- 每个时点从最新已公开的 VOO 股票名单选个股；VOO 只作名单和基准，不能成为策略买单。
- 不额外加入市值、流动性、成交额、股价门槛，也不使用旧的 865 个 SEC 主体名单作股票池。
- REIT、SPAC/壳、合伙单位、基金、债券、固定收益性质优先证券、权证等不入池；BRK.A 排除。获准的权益类优先股 ADR 不能仅凭 preferred 关键词排除。
- 目标满仓、周度检查、允许继续持有；不加市场择时、固定比例止损、做空或杠杆。
- 本金 100,000 美元，整股；每笔实际买或卖收 1 美元；工程滑点 5 bp/边，按不利方向处理。
- 工程配置：L=20、N=10、行业上限 k=3、缓冲 b=2。它们只是未验证的可运行基准，不是最优参数。本阶段不跑网格。
- 权重规则：只有当周发生换股（有退出或补位）时，才把全部可交易持仓恢复接近等权，以净股数差交易；当周没有换股时不下任何单，权重随价格自然漂移。原因是每笔固定 1 美元费用下，每周全面调权会持续产生小额调整单。正常的排名波动不强制换股。

## 四、输入与时间规则

采用简单 CSV/JSON 输入和 CLI。必须把以下含义清楚区分，字段可依据配套实施计划组织：

- 名单：`snapshot_id`、`holdings_as_of`、带时区 `available_at`、时间精度、来源/哈希、取得时间、证券明细。
- 证券：稳定 `security_id`、`issuer_id`、ticker/有效期、证券类型、行业与来源版本。
- 行情：证券、session 日期、未复权开盘和收盘，类别选择所需的成交额/成交量可选；美元计价。
- 事件：唯一 ID、证券、类型、生效 session、每旧股对应的新股数、现金金额及其口径、实际派息日。
- 日历：显式 session、开盘和收盘时间。不能用简单周一到周五规则冒充 NYSE 日历。

内部时间比较统一使用带时区 UTC；美东展示使用 `America/New_York`，避免把夏令时写死为 UTC-5。

只有所属日不晚于信号且已经公开的名单才能使用。先取最新所属日，再取当时可知的最新修订。`retrieved_at` 不决定历史可用性。只有公开日期时，从该日之后第一 session 开盘起可用；公开时间完全未知的文件不得混入可复现主流程。

信号来自每周最后 session 收盘，交易来自下一 session 开盘，不能同一收盘算完信号又假设已按该收盘成交。提前收盘日按输入收盘时间处理。最后一个信号没有下一 session 时记录未执行，不凭空补一个交易日。

所有模拟快照也必须有明确公开时间，不能让它们默认从数据起点全部可见。

## 五、评分与名单逻辑

1. 用统一总回报评分序列，计算 `TRI(t)/TRI(t-L)-1`；窗口需要 L+1 个有效 session 数据。
2. 不足历史和价格缺失分别报告，不用 0 或未来数据填补；不加一年历史或 63 日流动性条件。
   新候选历史不足可以暂不评分；已持有股票因输入缺口无法评分时，不把缺分当作掉队卖出。无法修复则明确失败并保存最后可解释状态。
3. 同一发行人先选一个股票类别，再评分；类别选择不依赖趋势分数，时间线在不同 L/N 下应一致。按规格的近期成交额口径选择仅是类别取舍，不是资格门槛；缺少该字段用稳定标识降级并记录，不能排除公司。
4. 同分用稳定 `security_id` 作次序，输入 CSV 行顺序不能改变结果。
5. 构造考虑行业 k 容量的可行顺序 F；缓冲线来自 F 第 `min(ceil(b*N),len(F))` 个候选的完整排序键，而不是原始股票排名前 2N。
6. 原持仓仍合格且排序不差于缓冲线，可进入保留集合。不要误写成“必须属于 F 才保留”。
7. 先按行业上限减少低分保留，再按总数 N 减少，然后从最高分的未持有候选补位，不能重复发行人。
8. 原持仓离开最新可用 VOO 名单或成为排除品种，应生成退出意图。
9. 名单选择函数在相同评分、行业、资格和已合规持仓下再次运行，不能为了换股而空转。
10. 填不满 N 时明确报告，不借 ETF、池外股票或放宽行业上限凑数。正常可交易路径按实际持仓数配置资金。

第一阶段只支持正常可交易持仓的选择路径。完整冻结/应收证券占位由阶段三完成，不要这次扩成一套事件驱动实盘系统。输入若包含该类未支持事件，明确失败并输出问题上下文，不能错误卖出或删除它后继续。

## 六、评分收益与账户账本

两者必须分开：评分里的假设再投资不等于账户已有现金。

本阶段支持：

- 拆合股：调整实际股数；评分不出现机械性涨跌；使用明确的“每旧股变成多少新股”字段，不直接套未核实 SDK 比例。
- 信号与成交之间的拆合股：信号在收盘计算、成交在下一 session 开盘。若拆合股在执行 session 生效，先把现有持仓股数和信号时的参考价格按“每旧股对应新股数”换算，再计算目标股数与净差。不能把拆股前的股数与拆股后的价格混用。
- 分红归属：以除息日前一个 session 收盘时的持股为准。除息日当天开盘卖出的股票仍享有该次分红；除息日当天开盘买入的股票不享有。
- 普通现金分红：评分假设除息日收盘再投资；账户除息日确认应收，实际派息日才转可用现金。股息权益按实际持有条件确认，不能持有一股却收两次分红。
- 每日总权益至少能拆为股票价值、可用现金和应收现金。
- 买卖数量是整数，先卖后买，按成本预算下单。现金不得为负，不融资；零数量差不计交易费用。
- 不同时对同一证券生成先卖再买；正确计算净差额。
- 同一事件 ID 重放不得再次入账。新开一次相同输入的 demo 应给出同样经济结果。

构造数据时明确事件顺序和现金金额口径。1 拆 2 的股数翻倍、价格约减半不会自动创造或损失一半权益；除息价格下降和应收股息合计应正确。

分拆、合并、收购、退市等本阶段只识别为未支持项，输出证券、事件、日期和原因并非零退出；保留诊断产物，不能生成标为成功的完整回测结果。不要使用任意统一退市折扣。

## 七、模拟数据和 VOO 基准

提供可复现小数据：至少 24 个虚构股票、至少 4 个行业、约 90 个以上 session、至少两份不同公开时间的名单。需要时用数个独立夹具测试不同边界，不把所有事件塞入一个巨大场景。

**至少一组夹具必须能真正测试保留缓冲。**在 N=10、k=3、b=2 下，保留线取可行次序 F 的第 `min(ceil(b×N), len(F)) = min(20, len(F))` 位。只有 4 个行业时，F 最多 12 只，保留线总是落在 F 的最后一位，缓冲逻辑实际上没有被测试。因此，这组夹具要让 len(F) > 20：至少 7 个行业、每个行业至少 3 只合格股票（建议 8 个以上行业、40 只以上股票）。也可以在单元测试中用更小的 N 和 k 构造同样的条件（保留线不落在 F 最后一位）。

必须包含：名单未来信息、成员移除、新成员、双股票类别、明确排除品种、拆股、除息与延后付款、周五休市或提前收盘。模拟数据写明生成规则/种子；不要只交一批没人能追溯的随机 CSV。

模拟基准可以使用 VOO 标签，但整个运行必须写 `dataset_kind=synthetic`。基准计算总回报、包含分红，开始时点与策略一致，仅是独立比较曲线。策略订单和策略持仓中不允许出现 VOO。

不要下载真实数据来证明 synthetic demo 收益合理，也不要把模拟跑出来的收益当成策略业绩。

## 九、必须跑的检查

测试要验证关键经济与时间行为，不只是复制实现公式后断言相等。少量可手算的例子配合端到端测试即可，不需要百万组合穷举。

1. 尚未公开的快照和后来修订不会影响此前信号；只改未来价格也不改变此前评分。
2. 周五休市、提前收盘和最后无下一 session 不造成交易时间错误。
3. 证券排除、BRK.A、同发行人去重、VOO 只作基准均生效。
4. 类别选择不随趋势参数变化，输入行重排不影响结果。
5. 原始高排名集中在单行业时，按可行顺序确定缓冲线；有足够候选时能满足 N 和 k。必须实际测到“保留线不落在 F 最后一位”的情形：一只持仓排名下滑但仍在保留线以内时继续持有，跌破保留线时才退出。
6. 仍在保留区的原持仓可继续持有；选择结果再次输入不会出现无意义替换。
7. 1 拆 2 没有虚假亏损；分红应收与到账、评分再投资不重复计账。拆股恰好在执行 session 生效时，目标股数正确；除息日开盘卖出仍获得分红，除息日开盘买入不获得分红。
8. 费用、滑点、整股取整和预算可手工核对；现金非负、资产科目一致。
9. 同一股票净差交易不先卖后买，同一事件不能重复处理。
10. 基准含分红且比较起点对齐；不把正常 VOO 基准当策略交易。
11. 未支持事件和错误输入显式失败并产生诊断，不被吞掉。
12. 实际端到端 demo 可运行，产物完整、经济结果可重复。
13. 没有换股的周不产生任何交易（包括权重调整单）；有换股的周才恢复接近等权。
