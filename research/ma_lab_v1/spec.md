# ma_lab：单只股票均线实验模块（v1）

登记 2026-10-28，先于代码。设计由投资者与审阅者定稿；本文只记录。

## 1. 目标

给一只股票、一个时间段、多种均线类型、多组快慢参数，算出每组均线策略的表现，并与同区间一直持有对比。以后换股票、换区间直接调用。本轮只做模块与一次微软演示，不做跨年挑参数、不做组合。

## 2. 数据与信号

| 项 | 取值 |
|---|---|
| 数据 | `tri_daily` 的日线总回报（含分红、拆股、分拆），`api.tri_series` |
| 起点 | 固定 2012-12-03（库里最早日期），终点为 `end` |
| 缺价 | 沿用前一日，同 `trend.py` 的 `carry_forward` |
| 预热 | 均线从 2012-12-03 起算，起始日之前的历史参与预热 |
| 信号日 | `[start, end]` 内每个周五（`api.friday_signal_days`） |
| 规则 | 当天收盘快线**严格大于**慢线为多，否则为空；快慢线同一种均线类型 |
| 历史不足 | 均线没有有效值时算作空 |

## 3. 持仓与评估

- 为多：从该周五收盘到下一个周五收盘全仓持有，权益按总回报变化；为空：现金。
- 现金收益：`zero`（默认）为 0；`dtb3` 按 `api.rf_daily` 每日计息。
- 零成本、小数股。
- 评估区间：从 `start` 当天或之后的第一个周五信号日收盘开始，到 `end` 当天或之前的最后一个交易日收盘结束。
- 一直持有：同一评估区间，从起点收盘全仓买入并一直持有。
- 截止日：`end > 2024-06-28` 报错；`start < 2012-12-03` 或 `start >= end` 报错。

## 4. 七种均线

| 类型 | 定义 | 第一个有效值 |
|---|---|---|
| `sma` | 最近 n 天简单平均 | 第 n 个观测 |
| `ema` | α = 2/(n+1)，第 n 个观测用前 n 天 SMA 作初值 | 第 n 个观测 |
| `wma` | 权重 n, n−1, …, 1，除以 n(n+1)/2 | 第 n 个观测 |
| `dema` | 2·EMA(n) − EMA(EMA(n), n) | 第 2n−1 个观测 |
| `tema` | 3·E1 − 3·E2 + E3 | 第 3n−2 个观测 |
| `hma` | WMA(2·WMA(n//2) − WMA(n), round(√n)) | 嵌套计算 |
| `kama` | ER = \|P_t−P_{t−n}\| ÷ Σ\|P_i−P_{i−1}\|；sc = (ER×(2/3−2/31)+2/31)²；KAMA_t = KAMA_{t−1} + sc×(P_t−KAMA_{t−1})；第 n+1 个观测用当天价格为初值 | 第 n+1 个观测 |

KAMA 的 2 与 30 为常量，不作为搜索参数。类型以"名称 → 函数"的字典登记，便于以后新增。

预热不足时照实计算，不改规则；每组报告"第一个有效信号日"，晚于评估起点时标 `warmup_short=1`。

## 5. 每组报的数字

年化（252 日，与 `metrics.py` 同口径）、总收益、年化波动、最大回撤及峰值/谷底/恢复日（未恢复为空）、年化 ÷ |最大回撤|、夏普（日收益减 `rf_daily` 日利率后，均值 ÷ 标准差 × √252，策略与一直持有同式）、在场比例（为多周数 ÷ 全部信号周数）、买入次数（由空转多）、平均每次持有周数、第一个有效信号日、`warmup_short`。

一直持有同表第一行，在场比例 1。

## 6. 演示运行

- 证券：MSFT（`CUSIP:594918104`）。
- 区间：2014-02-28 至 2024-06-28。
- 类型：7 种；快线 {5,10,20,30,50}；慢线 {50,100,150,200,250}，快线必须短于慢线 → 每种 24 组，共 **168 组**。
- 现金口径：`zero` 与 `dtb3` 各一次，共 336 次模拟。
- 输出：`work/ma_lab/MSFT_2014-02-28_2024-06-28_{cash}/`；`report.md` 与 `results.csv` 复制到 `research/ma_lab_v1/`，文件名带现金口径。

## 7. 输出格式

- `results.csv`：一直持有第一行，其后每组一行，含类型、快线、慢线及第 5 节全部字段。
- `report.md`：开头写股票、区间、现金口径、组合数；一直持有的数字；每种均线一张"快线 × 慢线"方阵（单元格：年化 / 最大回撤 / 收益÷回撤 / 夏普）；按收益÷回撤排序的前 10 与后 10；只写数字。
- `equity_daily.csv`：仅在 `--save-equity` 时输出，列为日期、一直持有、每个组合。

## 8. 本轮不做

不做跨年挑参数、不做组合、不加成本、不改 `engine.py` / `trend.py` / `signals.py` / 正式库 / `data/` / `AGENTS.md` / `research/` 下已有批次，不碰保留段，不新增第三方依赖，不推送。

## v2 变更（2026-10-28，投资者要求）

1. **每日检测。** 新增 `frequency='daily'`：每个交易日收盘用当天收盘价判断，当天收盘换手；评估区间从 `start` 当天或之后的第一个交易日收盘开始。`weekly` 保留为对照，默认仍是 `weekly`（与本文第 2 节一致），看板默认 `daily`。
2. **搜索范围扩大。** 快线 {3, 5, 8, 10, 13, 20, 30, 50}，慢线 {20, 30, 50, 80, 100, 150, 200, 250, 300}，快线必须短于慢线 → 每种均线 66 组，7 种共 **462 组**（原为每种 24 组、共 168 组）。
3. **每股排行榜。** `build_leaderboard.py` 对全部 317 个不歧义代码跑完整网格，每只股票在 462 组里取该指标最好的一组，再按指标给股票排名：总收益榜、年化榜、收益÷回撤榜、夏普榜。同时记录"只保留从起点就有效的组合"（`best_full`，即 `warmup_short=0`）的一版。**这是样本内最优，不能当作可预期收益。**
4. **配色。** 改用 Okabe-Ito 蓝（#0072B2）与橙（#D55E00）：买入 ▲ 蓝、卖出 ▼ 橙，矩阵底色蓝=较好、橙=较差，红绿色弱下仍可区分。
5. **看板。** 新增"单股图表 / 本股排行 / 全市场排行"三个视图、股票输入框（317 个不歧义代码）、每日/每周切换、对数轴、加载遮罩。
   - **本股排行**：当前股票自己的 462 组组合排行（总收益 / 年化 / 收益÷回撤 / 夏普），列出回撤、在场、买入次数、平均持有、首个有效信号日，可过滤掉预热不足的组合；点一行跳到单股图表。
   - **全市场排行**：每只股票取该指标最优组合后再排名（见第 3 条），点一行跳到该股详情。
