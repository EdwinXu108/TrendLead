# 动量组合网格 M2（零成本、绝对等权）

登记 2026-10-28，运行前写定。投资者在 `spec.md` 的五条规则之外，补充了持股数与两种等权方式。

## 固定（按投资者 2026-10-28 的决定）

| 项 | 值 |
|---|---|
| 本金 | 100,000 美元，单账户 |
| 成本 | **零**：滑点 0、手续费 0 |
| 股数 | 允许小数，**绝对等权**（每只 1/N） |
| 成交 | 信号日（周五）**收盘价**成交；基准 VOO 也从 2014-02-28 收盘起跑 |
| 换股 | 排名掉出前 N 就卖；空出的名额买当天排名最高、未持有的 |
| 建仓 | 一次买满 N 只，不留现金（池内不足 N 只时除外） |
| 分批 | **无**（K=1，单账户） |
| 缓冲 | **无**（b=1） |
| 名单 | 每个信号日只用当天生效的季度版本 |

## 两种等权方式（都跑，都记录）

- **R1**：只在"有换股"的那一周把持仓拉回各 1/N；没有换股的周不动。
- **R1W**：每个周五都把持仓拉回各 1/N（零成本，拉平不花钱）。

## 网格（660 个组合）

- 看多久 L：5–250 每 5 个交易日，另加 21、63、126、189、252 → **55 个**
- 持股数 N：**5、10、15、20、25、30** → 6 个
- 等权方式：R1、R1W → 2 种
- 55 × 6 × 2 = **660**

## 每个组合报

十年总收益、年化收益、相对 VOO 的年化超额、年化波动、最大回撤、年单边换手、平均持仓数。

## 口径说明

零成本意味着换手不扣钱，所以高换手的组合会显得比实际好。换手照常记录，将来加成本时直接用。

## 本批不做

- 不加滑点与手续费、不加缓冲、不分批；
- 不做随机对照、不拆时段、不设判定门槛；
- 不因为结果修改本批网格。
