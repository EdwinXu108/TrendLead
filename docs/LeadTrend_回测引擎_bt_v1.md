# LeadTrend 回测引擎 bt_v1

`leadtrend_bt/` 只通过 `leadtrend_db/api.py` 读取数据库，不导入、不修改 `leadtrend_v05`。测试在 `tests_bt/`。

## 规则

1. **信号日：**每周最后一个交易日（`friday_signal_days`）收盘后。在该日生效的股票池（`pool_at`）中，只对过去至少 L+1 个交易日都有总回报数据的证券评分。
2. **分数：**动量 = `tri_t ÷ tri_{t−L} − 1`。从高到低排名，同分按 `security_id` 排序。
3. **选股（保留缓冲 b）：**已持有且仍在池中、排名 ≤ b × N 的继续持有；不在池中或排名 > b × N 的卖出；空出的名额按排名补足到 N 只；同一公司的多个类别只取排名最高的一个。
4. **成交：**下一交易日开盘价；买入 = 开盘 × (1 + 滑点)，卖出 = 开盘 × (1 − 滑点)；每笔订单 1 美元；整股；现金不能为负；先卖后买。R2：保留的股票不调整仓位，卖出所得加现有现金在新买入之间等分；首次建仓等分 N 份。当日没有开盘价（停牌/缺日）的订单顺延到该证券下一个有开盘价的交易日。
5. **公司行动：**拆股/合股调整股数；现金分红在除权日计入现金；分拆在除权日按 `spin_value`（缺失时用复权因子隐含价值，再缺失时用除权日开盘缺口）折成现金。与 `tri_daily` 的 `event_v1` 完全同源。
6. **分批 K：**资金等分 K 份；子账户 j 在第 j 个信号周建仓，之后每 K 周检查一次；独立成交、独立计费；合并账户为各子账户之和。
7. **现金收益 0。**
8. **基准：**VOO 按总回报单位持有，起点为策略第一笔成交当日的开盘价（`units = 本金 ÷ (tri × open/close)`）。
9. **区间：**默认 2014-02-28 至 2024-06-28。`end > 2024-06-28` 抛 `HoldoutError`（保留段保护）。

## 配置项

`run_id, mode, start, end, L, N, b, K, cost_bps, fee_per_order, capital, seed, plan, buy_plan, top_n, weighting, top_m, w, buy_weighting, rebalance`

`mode`：`momentum`（默认）、`random`（随机对照，`plan` 给出每个信号日、每个子账户由原配置决定的卖出只数）、`pool`（参数化股票池：`top_n` 与 `weighting`）、`pool_ew`、`pool_cw`、`top10_cw`（旧别名）、`voo`（买入持有基准）。

## 股票池规模与权重（第 0 层）

`mode='pool'` 时，`top_n` ∈ {10, 20, 50, 100, 200} 为按当期公司持仓金额排名保留的公司数（只在可选公司中排，每家公司取持仓金额最大的可选类别）；`weighting` 为 `cw`（按基金持仓金额加权）或 `ew`（等权）。`top_n` 大于当期可选公司数时即为全部。旧模式 `pool_ew`、`pool_cw`、`top10_cw` 分别等价于 `top_n=None/ew`、`None/cw`、`10/cw`，输出逐字节相同。

## 范围、合成评分与按金额配权（第 3 层）

- `top_m`：每个信号日只保留当日股票池中持仓金额前 `top_m` 家公司（每家公司取金额最大的可选类别）作为可评分范围；持仓掉出范围视同离开股票池，在检查日卖出。`top_m` 不设或大于可选公司数时即为全部。
- `w`：合成分数 = `w × P_size + (1 − w) × P_mom`。`P_mom`、`P_size` 是在当日可评分样本内按平均秩换算到 0–1 的百分位（越大越好，同值同百分位）；按合成分数排名，同分按 `security_id`。`w` 不设或 0 时直接用原始动量，输出与旧引擎逐字节相同。
- `buy_weighting`：`equal`（默认，新买入等分）或 `amount`（按各新买入证券的基金持仓金额比例分配）。首次建仓与每个检查日的新买入都适用；保留的股票不调整仓位（R2）。

## 同规模随机（第 3 层）

`mode='random_size'`：卖出规则与随机对照相同；每个买入名额取原配置当日同序号买入的规模五分组（当日该配置范围内按持仓金额五等分），从该组按 hash 顺序选一只；组内无可用证券时按距离由近到远取相邻组，并累计 `size_fallback` 次数。`buy_plan` 给出原配置每个信号日、每个子账户的买入证券顺序。

## 核心加卫星（第 3 层）

`runner.run_core_satellite(core_cfg, sat_cfg)`：两个独立账户各自运行，逐日把现金、持仓市值、权益相加；某一部分尚未开始时按该部分本金计入现金。基准为全部资本在合并账户首个成交日开盘价买入 VOO。合并输出含 `daily_equity.csv`、`positions.csv`（同一天同一证券合并）、`trades.csv` 与 `weekly_decisions.csv`（带 `sleeve` 列）。

## R1 再平衡（第 2 层）

`rebalance='R1'` 时，在子账户的检查日只要有换股（有卖出或买入决定），就把该子账户的全部持仓按成交日开盘价恢复等权：目标市值 = 账户权益 ÷ 目标持仓数，只交易差额；没有换股的检查日不交易。`rebalance='R2'`（默认）保持原规则：保留的股票不调整仓位，卖出所得加现有现金在新买入之间等分。

## 随机对照（2026-10-27 更正 1）

在每个子账户的每个检查日：

1. **强制卖出：**已不在当日股票池中的持仓，必须卖出；
2. **随机卖出：**若原配置当日的卖出只数（按 `weekly_decisions.csv` 的 `sell` 决定统计，不按成交记录）多于强制卖出的只数，就在剩余持仓中按 `hash(seed, 信号日, security_id)` 的顺序再卖出差额那么多只；
3. **补足名额：**按同一 hash 顺序，从当日股票池中、不在持仓里、当日有总回报数据、且发行人不与现有持仓重复的证券中买入，直到持仓数等于 N；
4. 首次建仓买入 N 只；
5. 成交、成本、R2 资金分配、分批规则与原配置相同。

因此随机组合每个子账户在任何一天的持仓数都不超过 N，在每个检查日成交后等于 N（股票池不足 N 只时除外）。若某笔卖出因当日没有开盘价而顺延，成交层在该子账户已有 N 只持仓时不再执行买单，避免同一空缺席位被重复填补。

## 股票池调仓（2026-10-27 更正 1）

版本变更日按当日开盘价计算目标市值 = 目标权重 × 账户权益（现金 + 持仓按当日开盘价计值）：

- 不在新目标中的持仓全部卖出；
- 新目标中的证券只交易"目标市值 − 现有市值"的差额：差额为负卖出相应股数，为正买入；
- 差额绝对值不超过 1e-6 美元时不下单、不收手续费；
- 先卖后买，允许小数股；买单预算为差额，扣除手续费后按含滑点的价格折算股数。

## 集中度（2026-10-27 更正 1）

所有按持仓计算的集中度指标，先在同一天把同一证券在各子账户的市值相加，再除以合并账户总权益。`max_single_weight` 为合并后单只证券的最大权重；`max_top5_issuer_weight` 为合并后前 5 大发行人合计权重的最大值。`average_positions` 为每日不同证券数量（合并后）的平均，`average_positions_sum` 为各子账户持仓数之和的平均。

## 输出（`work/bt_runs/<run_id>/`）

| 文件 | 内容 |
|---|---|
| `config.json` | 本次配置 |
| `daily_equity.csv` | 日期、现金、持仓市值、总权益、VOO 基准值 |
| `trades.csv` | 日期、子账户、证券、方向、股数、成交价、费用、原因、信号日 |
| `positions.csv` | 每日每子账户持仓 |
| `weekly_decisions.csv` | 每个信号日的入选、保留、卖出、排名、分数 |
| `summary.json` | 全部指标 |

## 指标

CAGR（按 252 个交易日年化）、相对 VOO 的年化超额、年化波动、夏普（(CAGR − 区间平均 DTB3) ÷ 波动）、β、跟踪误差、最大回撤及峰值/谷底/恢复日、最长水下交易日数、逐年收益与超额、最差自然年、两个时段（A：2014-02-28 至 2019-11-29；B：2019-11-29 至 2024-06-28）的 CAGR 与超额、年单边换手、平均持仓数（合并后不同证券数与子账户合计两个口径）、最大单股权重、前 5 大发行人合计权重、平均仓位、前 5 大盈亏发行人及其占比。VOO 的同样数字一并输出。

## 验证（`tests_bt/`）

| 项 | 内容 |
|---|---|
| 合成数据 | 3–5 只证券、20 个交易日；手算成交价、手续费、整股取整、R2 现金分配、保留缓冲、拆股、分红、分拆、分批的建仓与检查日 |
| 不变量 | 每日总权益 = 现金 + Σ 股数 × 收盘价（1e-9）；现金不为负；同一信号日不买卖同一证券 |
| 基准一致 | 买入持有 VOO 的比值等于 tri 的比值（相对误差 1e-12） |
| 向量化对照 | 零成本、小数股、等权持有全池，与独立计算的权重漂移组合逐日一致（相对误差 1e-9） |
| 可重复 | 同一配置运行两次，输出文件逐字节相同（`tests_bt/test_repeatable.py`）；随机对照同一种子运行两次也逐字节相同（`test_amendment1.py`） |
| 随机持仓 | 随机组合每个子账户每日持仓数 ≤ N，每个检查日成交后 = N（股票池不足 N 只除外）；强制卖出多于原配置卖出只数时只执行强制卖出 |
| 集中度 | 两个子账户各持同一证券、各占合并权益 10% 时，最大单股权重 = 20% |
| 股票池调仓 | 目标不变时版本变更日不产生交易；只换 1 只证券时只产生该证券卖出与新证券买入；价格变动时其余证券按差额交易恢复目标权重 |
| 规模参数 | `top_n` 按持仓金额选公司并按金额/等权配置；`top_n` 超过可选公司数时持有全部 |
| R1 再平衡 | 检查日有换股时按成交日开盘价恢复等权；没有换股的检查日不交易；R2 在同一市场不调整保留持仓 |
| 信号层 | 信号与未来收益完全一致时 IC = 1；信号只用 t 及以前的数据；未来窗口越过 2024-06-28 报错 |
| 范围与合成评分 | `top_m` 截断可评分范围、掉出范围的持仓在检查日卖出；百分位为平均秩；`w=1` 只按规模排名；同分按 `security_id` |
| 按金额配权 | 首次建仓按持仓金额比例分配资金（3:1 的金额得到 3:1 的市值） |
| 核心加卫星 | 合并权益 = 两部分之和；较晚开始的子账户在开始前按现金计入 |
| 保留段 | 结束日晚于 2024-06-28 报错 |
