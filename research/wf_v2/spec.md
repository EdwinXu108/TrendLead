## 3. 开发段规则

### 3.1 不变的部分

- 股票名单：`ma_walk.stock_list`（318 只，不歧义且至少一行可选）。
- 462 组网格：7 种均线 × 快线 {3,5,8,10,13,20,30,50} × 慢线 {20,30,50,80,100,150,200,250,300}，快线短于慢线。
- 信号规则：收盘判断、当天收盘换手；快线严格大于慢线为多；零成本、小数股；现金不计息（本轮只跑 `daily` + `zero`）。
- 挑选日：2016 至 2023 年每年最后一个信号日；回看区间逐年拉长；挑选指标为回看区间的 年化 ÷ |最大回撤|；打平按类型顺序（sma, ema, wma, dema, tema, hma, kama）、快线小、慢线小取第一个；挑选日收盘换成新组合，用到下一个挑选日。
- 评估区间：2016 年最后一个信号日至 2024-06-28。
- `run_lab` 的行为不变。

### 3.2 修改一：只有全程有效的组合才能参选（修预热）

1. 每只股票的**评分起点 S**：不早于 2014-02-28，也不早于该股票第一个有数据的交易日之后的第 301 个交易日。
2. 组合可参选，当且仅当它的快线和慢线在 S 当天都已有有效值。回看区间从 S 到挑选日。
3. 回看区间不足 252 个交易日的挑选日跳过。
4. 在 S 当天仍无有效值的组合在这只股票上永远不参选，照实报告组数与名单。
5. 分开记录两种空仓：「尚无信号」（均线无有效值）与「有效信号为空」（均线有效但快线不高于慢线）。

### 3.3 修改二：逐股配对比较

对 B、C、D、E、F 每条线，每只股票计算「A − 对照」的年化差、最大回撤差、收益÷回撤差。汇总报三个差值的中位数、25%、75% 分位，以及胜/负/平/不可比只数（|差| < 1e-9 为平，任一方算不出为不可比）。两组：「评估从 2016 年开始」的股票与全部能算出结果的股票。

### 3.4 修改三：六条线

| 编号 | 线 | 规则 |
|---|---|---|
| A | 本股挑选（OWN） | 修预热后的逐年挑选 |
| B | 共同参数（COMMON） | 每个挑选日：每个组合取它在所有可参选股票上回看收益÷回撤的中位数；只考虑在至少 90% 的当年有挑选结果的股票上可参选的组合；中位数最高者当年共用；每只股票按自己的价格算信号 |
| C | 借参数（BORROW） | 每个挑选日把各股挑出的组合随机重新分给其他股票，不得分给自己；分到的组合在接收股票上不可参选时，从其余股票的组合里重抽，最多 100 次，抽不到记为不可比；只交换参数，信号按接收股票自己的价格算；种子 0–19，每只股票的指标取 20 次的中位数，并报告 20 次收益÷回撤的最小/最大值再取全股票中位数 |
| D | 固定 SMA 50/200 | 不变 |
| E | 一直持有 | 不变 |
| F | 同仓位股票 + 现金（MIX） | x = A 线评估区间在场比例；每日收益 = x × 股票当日收益，其余现金收益 0。事后归因，不是可执行方案 |

## 4. 保留段规则

1. 数据只用 `data/db/leadtrend_db_full_v1.sqlite`。
2. 窗口：2024-06-28 收盘记为 1，到 2026-06-30 收盘。
3. 冻结挑选：2024-06-28 再做一次挑选（回看 S 至 2024-06-28，规则同第 3 节，只用开发段数据）；A、B、C 挑出的参数在整个保留段固定不变；C 用种子 0–19；D、E 不变。
4. F 的 x 用 A 在开发段评估区间的在场比例，保留段开始前已确定。
5. 2024-06-28 收盘起，持仓状态等于冻结组合当天的状态，之后照常每日收盘判断。
6. 股票：2024-06-28 前已有挑选结果的股票；回看不足 252 个交易日的不进保留段并列出；保留段内退市或数据中断的照实处理、单独列出、不剔除不补位。
7. 报六条线的年化、总收益、最大回撤（含峰/谷/恢复）、收益÷回撤、夏普、在场、买入次数；逐年收益（2024 下半年、2025、2026 上半年分列）；第 3.3 节全部配对汇总；开发段与保留段的中位数并列表。
