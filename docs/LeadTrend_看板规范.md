# LeadTrend 看板规范

2026-10-29 起，所有看板（本地 HTML 页面）都按本文执行。旧看板不符合的地方，重做时一并改掉。

## 1. 每页一句话

每页开头一句话，说明这页回答什么问题，不超过 40 个字。这句话放在页面最上方，字号大于正文。

## 2. 一个格子只放一个数

- 禁止用斜杠、顿号或“胜 / 负”把多个数字串进同一格，例如 `6.0% / 3.7% / 5.7%`、`胜 162 / 负 124`。
- 多个数就拆成多列，或拆成多行；每格只留一个数字和一个单位。
- 说明文字（例如“胜 = 本股挑选更好”）放在表下一行，不放进格子。

## 3. 数字格式统一

- 右对齐，等宽数字（`font-variant-numeric: tabular-nums`）。
- 百分比保留 1 位小数，比值保留 2 位。
- 负收益、更深的回撤用 `--bad` 色，其余用正文色；不使用红绿以外的花色。
- 缺失值写 `—`，不写 0，也不留空。

## 4. 每张图默认最多 4 条线

- 默认显示不超过 4 条；其余可以勾选，但默认关闭。
- 图例必须写清哪条是哪条；勾选框与图例放在一起。

## 5. 中文全名，不出现内部代号

- 图例、表头、卡片标题都用中文全名，并配一句话解释。例如“同仓位：不择时，一直只拿与均线策略相同的平均仓位”。
- 主界面不出现 a/b/c、P0/P2、seed、wf2、cagr_over_dd 这类代号；需要时放在“这页怎么读”里。

## 6. 同一条线在所有页面颜色相同

用 Okabe-Ito 色板，固定对应关系：

| 线 | 颜色 |
|---|---|
| 本股挑选 / 看多满仓 | `#0072B2` 蓝 |
| 共同参数 | `#56B4E9` 天蓝 |
| 借参数 | `#CC79A7` 紫 |
| 固定 50/200 | `#E69F00` 黄 |
| 一直持有 / 全部等权 | `#666666` 灰 |
| 同仓位 / VOO | `#009E73` 绿 |

## 7. 与当前页无关的控件必须隐藏

- 每页只显示自己用得到的控件；汇总页不显示均线类型、快慢线、起止日期、“重新计算”。
- 控件隐藏用 `hidden`，不要留空位。

## 8. 长说明放进默认折叠的“这页怎么读”

页脚放一个 `<details>`，默认收起，里面写口径、代号对照、已知限制。页面上只留一句话和必要的表注。

## 9. 加载中、无数据、出错三种状态都要有中文提示

- 加载中：页面上显示“正在读取…”。
- 无数据：写清缺什么、怎么生成，例如“请先运行 research/pool_ma_v1/run_pool_ma.py”。
- 出错：显示错误信息，不留白屏。

## 10. 宽度适配

- 宽 1400 与宽 900 都不出现整页横向滚动条。
- 宽表放在自己的容器里横向滚动，容器有边框提示。
- 图表宽度跟随容器，不用固定像素。

## 11. 一页只讲一件事

- 被新结果取代的页面直接删掉，不保留入口，也不保留 API。
- 当前页面清单：组合实验（首页）、单股均线、单股滚动验证、滚动验证汇总、全市场排行。

## 12. 页面与控件对照

| 页面 | 回答的问题 | 控件 |
|---|---|---|
| 组合实验 | 只买均线看多的股票，比随机买同样多只股票更好吗？ | 无（只有图的勾选） |
| 单股均线 | 一只股票的均线组合，历史上哪组最好？ | 股票、起止日期、现金、信号频率、均线类型、快慢线、重新计算 |
| 单股滚动验证 | 每年重挑一次参数，这只股票表现如何？ | 股票、开发段/保留段 |
| 滚动验证汇总 | 本股挑选比对照线好多少？ | 开发段/保留段、全部/剔除晚入池 |
| 全市场排行 | 每只股票最好的均线组合是什么？ | 信号频率、现金 |
