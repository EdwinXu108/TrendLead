# pool_ma_v1：按当时名单的组合均线小实验

登记 2026-10-29，先于代码。设计由投资者与审阅者定稿；不得增减配置，不得搜索参数。

## 1. 要回答的问题

**只持有均线看多的股票，是否比“随机持有同样数量的股票”和“持有全部股票”更好？**

如果“看多满仓”赢了“看多 + 现金”，却没有赢过“随机同数量”，那只说明仓位更满，不说明均线会挑股票。报告只写数字，不写这样的结论。

## 2. 口径（信号层）

| 项 | 取值 |
|---|---|
| 时段 | 2014-02-28 至 2024-06-28，一整段 |
| 信号日 | `api.friday_signal_days('2014-02-28', '2024-06-28')`（每周最后一个交易日） |
| 成交 | 信号日收盘出信号，同一收盘价成交 |
| 成本 | 零 |
| 股数 | 小数股 |
| 本金 | 100,000 美元 |
| 现金 | 不计息 |
| 数据库 | `data/db/leadtrend_db_v1.sqlite`，所有 `api` 调用 `end ≤ 2024-06-28` |

## 3. 股票池（按当时名单）

- 每个信号日 d：取 `api.pool_at(d)` 当天生效的版本；用与引擎相同的方法每家公司取一个代表类别：
  `engine.Backtest._representatives(api.pool_amounts(v), api.pool_company_amounts(v))`；得到当天的池 U_d，M_d = |U_d|。
- 只用当时生效的名单，不得用后来的名单回填。
- 被永久排除的公司、构建日退市过滤，都沿用数据库现状，不改。后者在报告里写为已知限制。

## 4. 信号

- 固定 **SMA 50/200**：用每只证券自己的 `tri_daily` 日线总回报计算，覆盖库内完整历史（2012-12-03 起）。
- 直接复用 `leadtrend_bt/trend.py` 的 `matrix`、`carry_forward`、`bullish('sma', 50, 200)`，口径与 trend_v1 完全一致：
  快线严格大于慢线为多；历史不足 200 天算作空；单日缺价沿用前值。
- 记当天看多的股票集合为 B_d ⊆ U_d，K_d = |B_d|。

## 5. 五个组合与一个基准

每个信号日收盘，把组合调到下表的目标权重。两个信号日之间股数不变，按 `tri` 每日估值，权重自然漂移。

| 名称（中文，看板用） | 代号 | 目标权重 |
|---|---|---|
| 全部等权 | P0 | U_d 中每只 1/M_d |
| 看多 + 现金 | P1 | B_d 中每只 1/M_d，其余现金 |
| 看多满仓 | P2 | B_d 中每只 1/K_d；K_d = 0 时全部现金 |
| 随机同数量 | P3 | 从 U_d 中不放回随机抽 K_d 只，每只 1/K_d；K_d = 0 时全部现金。每周重抽。种子 0–99，共 100 条 |
| VOO | — | `BENCH:VOO` 总回报，买入持有，取法与引擎一致 |

P3 随机数用 `numpy.random.default_rng(seed)`，按信号日顺序抽取，结果须完全可复现。

**边界处理**（报告中计数）：

- 证券在信号日没有 `tri`：沿用前值。若该证券此前从未有过 `tri`，当天不进入 U_d，计数。
- 持有中的证券 `tri` 序列提前结束：从最后一个值起按 0 收益计，相当于冻结成现金，到下一个信号日卖出。计数。
- 版本切换：只在信号日按 `pool_at(d)` 生效。掉出池的股票当天卖出；所有组合本来每周都调仓。

## 6. 每条线要报的数字

全部从同一条日净值计算，起点为 2014-02-28 收盘；尽量复用 `leadtrend_bt/metrics.py` 现有函数。

- 年化（按总资本，含现金）、总收益
- 相对 VOO 的年化超额（组合年化 − VOO 年化）
- 最大回撤，及其峰值、谷底、恢复日期（未恢复写空）
- 最长水下交易日数
- 2020 年内、2022 年内的最大回撤
- 每个自然年收益（2014、2024 标为不完整年）、最差自然年
- 年化 ÷ |最大回撤|（参考）、夏普（无风险利率按 0）
- 平均股票仓位、平均持股只数、年均单边换手

P3 报 100 条的中位数、5% 分位、95% 分位。另报 **P2 在每个指标上胜过多少条随机线**（满分 100）：年化、最大回撤、最长水下、收益÷回撤。

诊断数字：K_d 的均值、最小值、最大值，K_d = 0 的周数；M_d 的均值、最小值、最大值；第 5 节各边界情况的计数。
