# LeadTrend：项目状态与信号实验结果

日期 2026-10-28。写给外部审阅者（人或其他 AI）。读完这份文档应当能独立理解：这个项目在做什么、数据是什么、跑过哪些实验、本轮 13 个信号的结果、以及哪些地方不能过度解读。所有数字都可以用仓库里的文件复现。

---

## 1. 项目与目标

- **研究对象**：美股。股票池是 VOO（先锋标普 500 ETF）各季度实际持仓中，按持仓金额排名前 200 的公司。每周五收盘按某个信号排序，买入排名最高的 N 只，等权持有，下周五检查。
- **基准**：VOO 本身（按总回报计算）。投资者不买 ETF，VOO 只作基准。
- **目标**：通过选股跑赢 VOO。
- **硬约束**：零付费数据；不使用行业或板块标签（投资者否决，改用长期股价相关性）；保留段（2024-07-05 起）不得用于任何计算。

## 2. 数据库

### 2.2 时点规则

每个季度版本来自 VOO 向 SEC 提交的持仓报告。版本从**报告公开时间**（SEC 受理时间，精确到秒）起生效：纽约开盘前公开的当日可用，否则下一交易日起用。因此新进入 VOO 的股票最多晚一个季度进入股票池——这是季度披露的物理限制。

每家公司只取**持仓金额最大的那个可选类别**（例如 Alphabet 只取 GOOGL 或 GOOG 之一），避免同一公司重复下注。

### 2.3 已做的数据修正（2026-10-27 至 28）

1. **现金与分拆对账**：44 条现金分红按官方来源修正，Google 类分配、GE 医疗/GE Vernova 分拆、DowDuPont 分拆按子公司收盘价重新估值；受影响的 TRI 曲线整体重算。
2. **排除 ACE 与 CMCSK**：投资者决定。OpenD 没有这两个代码，ACE 在 2016 年前的历史属于被收购的旧 Chubb，CMCSK 只有 CMCSA 代理且价格基准不符。两者从所有季度的策略名单移除，价格历史保留。
3. **补齐 SPGI 的 2016 年缺口**：2016-04-28 至 05-23 共 18 个交易日，用 Yahoo 的 17 天真实行情补齐（Yahoo 有一个错误的 1057:1000 拆股，已按 1.057 还原），2016-04-28 用前收盘占位。
4. **缺一日容忍**：回看窗口允许缺 1 个交易日，仍按两端点算动量并标记；缺 2 天以上不评分。

### 2.4 已知的、仍然存在的缺口

| 问题 | 范围 | 影响 |
|---|---|---|
| 单日行情缺失 | BIIB 2020-11-06、REGN 2015-06-09、VRTX 2015-05-12 | 已被"缺一日容忍"覆盖，不再阻断评分 |
| 分拆按代理估值 | 22 个分拆中 8 个（4 个用复权因子、4 个用除权日开盘缺口） | 估值有误差，已在 `resolution` 标注 |

| 幸存者 | 池子只含截至 2026-10-26 仍在上市的公司（投资者决定） | 结果不含被收购/退市的公司 |

### 2.5 可重建性

数据库由"封存基库 + 三步登记迁移"生成，任何一步都能重跑并逐字节比对：`development_release`（现金/分拆对账）→ `pool_exclusion_release`（排除两只）→ `spgi_fill_release`（补 SPGI）。原始文件（OpenD 行情、SEC 申报、Yahoo 返回）全部归档在 `data/db/raw/`。

## 3. 本轮的交易口径（投资者 2026-10-28 决定）

| 项 | 值 |
|---|---|
| 本金 | 100,000 美元，单账户 |
| 成本 | **零**（滑点 0、手续费 0）——本轮只探索信号，不模拟成本 |
| 股数 | 允许小数，绝对等权（每只 1/N） |
| 成交 | 周五收盘出信号，**当天收盘价**成交（投资者实际操作方式） |
| 换股 | 排名掉出前 N 就卖；空出的名额买当天排名最高的 |
| 缓冲/分批 | 都没有（b=1、K=1） |
| 基准 | VOO，同样从 2014-02-28 收盘起跑 |

需要说明：零成本意味着换手不扣钱，所以高换手的组合会显得比实际好。换手率在结果表里全部列出。

## 6. 观察

以下是我从数字里读到的，不是结论，供讨论。

**6.1 反转是这十年里最强的信号。**
`REV_5` 在 6 个持股数上全部为正（+3.76% 到 +5.84%），信号层 IC +0.015（4 周），是所有信号里最高的之一。但它的年换手 **4749%**——每周几乎全换。按 10bp 单边算，一年成本约 4.7%，正好把超额吃光。`REV_21` 类似，换手 2607%。

**6.2 低波动在这十年是负的，高波动是正的。**
`LOWVOL_126` 全部为负（−1.3% 到 −5.1%），`HIGHVOL_126` 全部为正（+0.1% 到 +2.9%）。信号层的 IC 也一致：低波动的 IC 是 **−0.037**（13 周），高波动是 +0.037。这和经典的"低波动异象"方向相反。可能的原因：这十年的大牛股本身就是高波动成长股，而低波动组合天然偏防御。

**6.3 "接近 52 周高点"是负的。**
`DIST_52W` 全部为负（−3.6% 到 −7.8%），IC −0.016。经典的"52 周高点动量"在这批股票里反向。

**6.4 基金加仓是负的，而且是所有信号里最差的。**
`FUND_ACCUM` 在 N=5 时 −11.6%，随 N 增大改善到 −1.2%。`FUND_RANK_UP` 类似（−8.9% 到 −0.5%）。也就是说：**基金上一个季度加仓最多的公司，接下来跑输**。这可能是"基金追高"的反向证据，但也可能只是与规模/动量的负相关。

**6.5 动量本身接近零或负。**
`MOM_126`：−3.7% 到 +1.4%；`MOM_252`：−3.9% 到 −1.3%。唯一全为正的动量变体是 `MOM_12_1`（+0.39% 到 +4.69%），即跳过最近一个月的版本——这与"短期反转、中期动量"的经典结构一致。

**6.6 所有正结果的换手都很高。**
正超额的信号（REV_5、MOM_12_1、HIGHVOL）年换手都在 480%–4749%；换手低的（LOWVOL 516%、AMIHUD 428%、FUND_ACCUM 420%）全部为负。这不是巧合：在这个池子里，**能赚钱的排序变化很快，稳定的排序不赚钱**。

## 7. 不能过度解读的地方

1. **零成本**。所有正超额都还没扣交易成本。REV_5 的 4.7% 年换手成本会直接吃掉它的超额。
2. **多重检验**。本轮 78 个组合，加上之前的 660 个网格和 13,440 个信号格，一共上万次测试。78 个里出现几个 +4% 到 +6% 是正常的。
3. **单一市场、单一十年**。2014–2024 的美股是超大市值主导的十年，结论未必能外推。
4. **池子只含幸存公司**（投资者决定），不含被收购/退市的公司。
5. **信号层与组合结果并不总一致**。例如 `DIST_52W` 的 IC 只有 −0.016，但组合超额 −7.8%，说明组合结果受尾部（最极端的几只）影响很大，不能只看 IC。
