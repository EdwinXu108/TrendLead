# 相关性分析 C1：top50 / top100 的股价相关性

登记 2026-10-28，运行前写定。本批**只做统计**，不交易、不改引擎、不动保留段。

## 要回答的问题

1. 在每个季度时点，池子里**最大的 50 家 / 100 家**公司，股价彼此有多像？
2. 这个"像"随时间怎么变？现在比十年前更挤还是更松？
3. top50 是否比 top100 更挤？top100 是否比全池更挤？
4. 哪些配对是**长期结构性**地像（不是某一年偶然）？
5. 如果只买 N 只，实际相当于几个独立下注？

## 口径（运行前固定，不因结果调整）

| 项 | 取值 |
|---|---|
| 时点 | 开发段 43 个季度版本生效日（2014-02-28 至 2024-05-30），不使用保留段 |
| 名单 | 当日生效版本中，按公司级持仓金额 `amount_cents` 降序取前 50 / 前 100 家 |
| 公司级去重 | 每家公司只保留金额最大的那个可选类别（库内已验证无重复发行人） |
| 收益 | `tri_daily.daily_return`（日总回报，已含分红、拆股、分拆） |
| 窗口 | 截至时点 T（含 T）的 252 个交易日；不足 252 个交易日则跳过 |
| 相关系数 | Pearson，**成对完整观测**（pairwise complete）；共同观测 < 200 天的证券剔除 |
| 两种口径 | 原始 ρ（含大盘 beta，看"整体有多挤"）；去市场 ρ（减去当日名单内等权平均，看"谁和谁像"） |
| 对照 | 全池（162–201 只） |
| 零方差处理 | 该证券与其他证券的相关系数记 0 |

**为什么用日收益不用收盘价**：两只都在涨的股票，价格序列相关性可以到 0.9，那是趋势不是共同波动。用价格算出来的数没有解释力。

**为什么去市场后平均 ρ 必然≈0**：减去当日等权平均等于把共同成分扣掉，剩下的就是相对波动。所以去市场 ρ 只能看排序和结构，不能看整体水平。

## 每个时点、每个范围报的数字

- 配对数、平均 ρ、中位数、标准差、5/25/75/95 分位
- ρ > 0.5、ρ > 0.7、ρ < 0 的配对占比
- 最高的一对（代码与 ρ）
- 等效独立注数两种算法：算术 `k/(1+(k-1)ρ̄)`、特征值参与率 `(Σλ)²/Σλ²`
- 去市场 ρ 的标准差与 ρ > 0.5 占比
- 窗口实际长度、平均共同观测天数

## 跨时点统计

- 43 个时点均值的分布（均值、标准差、最小/最大、四分位）
- 时间趋势：对时点均值做 OLS，Newey-West t（滞后 4 个季度）
- top50 与 top100 的配对差（同一时点相减），均值与 t
- 按自然年汇总
- 结构性配对：出现 ≥ 10 个时点的配对，按平均 ρ 排序
