# 动量实验 M1：从一周到一年，动量期限结构 × 持股数

登记 2026-10-28，在任何结果产生之前写定（第一版只含 63–252，同日改为从 5 个交易日开始，尚无任何运行结果）。数据为修正后的正式库 `development_release_v1 + pool_exclusions_v2 + spgi_fill_v1`。

## 问题

1. 动量的预测力随回看长度怎么变？从 1 周（5 个交易日）到 12 个月，哪一段真的有信号？
2. 把这个信号做成组合（等权、每周检查）后，持股数 N 如何影响超额？
3. 最短的回看（5 日）在扣掉换手成本后还剩多少？

## 两层设计（为什么分两层）

- **信号层（M0）**：不交易、不扣成本，直接在 248 个回看长度上算 IC 与分组价差。这是"极致精准"该发生的地方——粒度可以到 1 个交易日，成本几乎为零。
- **回测层（M1）**：只在 9 个代表点上跑组合，把信号翻译成扣成本后的超额。回测每次 40 秒，248 个长度全跑要 20 多小时，而且多出来的精度会被噪声淹没。

## M0：信号层扫描（描述性）

| 项 | 值 |
|---|---|
| 回看 L | **5 至 252，每个交易日数**（248 个） |
| 信号 | `MOM_L = tri_t ÷ tri_{t−L} − 1` |
| 样本 | 每个信号日、当期池内每家公司一个证券（金额最大的可选类别），只纳入端点有总回报的 |
| 前向收益 | t 收盘至其后第 h 个信号日收盘，h ∈ {1, 4, 13} 周 |
| 每个 L 报告 | IC 均值、Newey-West t（滞后 h 周）、为正比例、A/B 两段均值与 t；五组 Q5−Q1（年化）与单调性 |
| 用途 | 画出"动量期限结构"曲线，描述信号在哪一段最强；**不用于挑选 M1 的格子** |

## M1：回测网格（36 格）

## 固定不动

| 项 | 值 |
|---|---|
| 股票池 | 当期版本的前 200 家公司，每公司取基金持仓金额最大的可选类别 |
| 信号日 | 每周最后一个交易日收盘 |
| 成交 | 下一交易日开盘，先卖后买，整股；滑点单边 5/10bp；每笔 1 美元 |
| 保留缓冲 | b = 2（排名 ≤ 2N 继续持有） |
| 再平衡 | R2（保留的股票不调仓，卖出所得在新买入之间等分） |
| 分批 | K = 1（每个信号日都检查） |
| 权重 | 等权（新买入资金等分） |
| 区间 | 2014-02-28 至 2024-06-28；A 段 2014-02-28–2019-11-29，B 段 2019-11-29–2024-06-28 |
| 基准 | VOO；参照线 TOP10_CW（前十大金额加权，10bp 超额 +4.84%） |

## M2：条件细化（只在 M0 给出明确区间时执行）

若 M0 中存在连续 3 个以上回看长度同时满足「IC 均值 > 0」且「NW t ≥ 1」，则在该区间按 5 个交易日步长细化回测，N 固定 10 与 20。该规则写在运行之前，不因结果改口。

## 指标

CAGR、相对 VOO 的年化超额、年化波动、夏普、β、跟踪误差、最大回撤及日期、最长水下、年单边换手、平均持仓数、最大单股权重、A/B 两段超额、逐年超额，以及超额 t 值（`超额 ÷ 跟踪误差 × √年数`）。

## 判定规则（事先写死）

1. M0 只描述，不选配置。
2. M1 的 36 格全部报数字。
3. 阶段 2 的随机对照（100 次，种子 0–99）与起点推迟 1–4 周，只对同时满足「全期超额 > 0」且「A、B 两段超额都 > 0」的格子做；若没有格子满足，则对全期超额最高的 2 格做，并标注"事后选择"。
4. "有效"的门槛：10bp 超额 > 0、A/B 两段都 > 0、随机百分位 ≥ 90、t ≥ 1。四条不全满足的只报数字。
5. 不以 B 段单独的表现作为选择依据。
