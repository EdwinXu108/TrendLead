# 动量实验 M1：回看长度 × 持股数

登记时间 2026-10-28，在任何结果产生之前写定。数据为修正后的正式库 `development_release_v1 + pool_exclusions_v2 + spgi_fill_v1`。

## 问题

在纯动量选股、等权、每周检查的骨架下：

1. 动量选股能否跑赢 VOO？
2. 回看长度 L 与持股数 N 各自如何影响超额？曲面是单调的、有峰值的，还是噪声？

## 固定不动

| 项 | 值 |
|---|---|
| 股票池 | 当期版本的前 200 家公司，每公司取基金持仓金额最大的可选类别 |
| 信号日 | 每周最后一个交易日收盘 |
| 信号 | `MOM_L = tri_t ÷ tri_{t−L} − 1`，只用 t 及以前的数据 |
| 成交 | 下一交易日开盘，先卖后买，整股；滑点单边 5bp 与 10bp；每笔 1 美元 |
| 保留缓冲 | b = 2（排名 ≤ 2N 继续持有） |
| 再平衡 | R2（保留的股票不调仓，卖出所得在新买入之间等分） |
| 分批 | K = 1（每个信号日都检查） |
| 权重 | 等权（新买入资金等分） |
| 区间 | 2014-02-28 至 2024-06-28；A 段 2014-02-28–2019-11-29，B 段 2019-11-29–2024-06-28 |
| 基准 | VOO；另列参照线 TOP10_CW（前十大金额加权，10bp 超额 +4.84%） |

## 网格（16 格）

- L ∈ {63, 126, 189, 252}（3、6、9、12 个月）
- N ∈ {5, 10, 20, 30}
- 每格跑 5bp 与 10bp

## 指标

CAGR、相对 VOO 的年化超额、年化波动、夏普、β、跟踪误差、最大回撤及日期、最长水下、年单边换手、平均持仓数、最大单股权重、A/B 两段超额、逐年超额，以及超额的 t 值（`超额 ÷ 跟踪误差 × √年数`）。

## 判定规则（事先写死，运行前不改）

1. **阶段 1**：16 格全部报数字，不选配置、不下结论。
2. **阶段 2**：只对同时满足「全期超额 > 0」且「A、B 两段超额都 > 0」的格子做 100 次随机对照（种子 0–99）与起点推迟 1–4 周；若没有格子满足，则对全期超额最高的 2 格做，并在报告中标注"事后选择"。
3. **"有效"的门槛**：10bp 超额 > 0、A/B 两段都 > 0、随机百分位 ≥ 90、t ≥ 1。四条不全满足的，只报数字，不称为有效。
4. 不以 B 段单独的表现作为选择依据。
