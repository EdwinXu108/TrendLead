# trend_v1：个股均线趋势实验（第一轮）

登记 2026-10-28，运行前写定。设计由投资者与审阅者逐条定稿，本文件只记录、不解释。信号层口径，不做回测层。

## 1. 要回答的问题

在 VOO 持仓金额最大的前 N 家公司里，每只股票单独用日线均线交叉判断自己的趋势：趋势为多就持有，转空就卖成现金。问这样的组合能否用"不错的回报 + 明显更小的回撤"换掉"一直持有"。不要求比一直持有赚得多。

与横截面排序无关。结果只放在 `research/trend_v1/`。

## 2. 口径

| 项 | 取值 |
|---|---|
| 信号日 | 每周最后一个交易日（`api.friday_signal_days`），2014-02-28 至 2024-06-28，一整段 |
| 成交 | 周五收盘出信号，当天收盘价成交（`execution='close'`） |
| 成本 | 零（滑点 0、手续费 0） |
| 股数 | 小数股 |
| 本金 | 100,000 美元 |
| 协议 | `research_v1` |
| 数据 | `data/db/leadtrend_db_v1.sqlite`，所有 `api` 调用的 `end` ≤ 2024-06-28 |

## 3. 股票池

- 每个信号日取当天生效的季度版本（`api.pool_at`），按**公司级持仓金额**（`api.pool_company_amounts`）取前 **N** 家公司，N ∈ {5, 10, 15, 20}。
- 每家公司只取持仓金额最大的可选类别（与 `signals.context` 的去重一致，即 `engine._representatives`）。
- 公司级金额来自 `pool_company_amounts`，它包含不可购买的类别；若某公司没有任何可购买类别，跳过该公司，由下一名公司补足到 N 家。

## 4. 信号

- 均线用每只证券自己的 `tri_daily` 日线总回报计算，覆盖库里完整历史（2012-12-03 起），与何时进入股票池无关。
- 均线在全库交易日历上计算；某证券单日缺价时沿用前一日的值（该日回报视为 0），不让整条均线作废。
- 周五收盘时**快线严格大于慢线为多**，否则为空。
- 23 条规则：

| 类型 | 参数 |
|---|---|
| SMA 交叉 | (10,50)、(10,100)、(10,150)、(10,200)、(20,50)、(20,100)、(20,150)、(20,200)、(50,100)、(50,150)、(50,200) |
| EMA 交叉 | 同上 11 组 |
| MACD | (12,26,9)：MACD 线 = EMA12 − EMA26，信号线 = MACD 线的 EMA9，MACD 线严格大于信号线为多 |

- **EMA 起点：**用前 n 天的 SMA 作为第 n 天的 EMA 初值，之后按 α = 2/(n+1) 递推。
- **历史不足：**SMA/EMA 不足 slow 天、MACD 不足 26+9−1 = 34 天，算作空。

## 5. 持仓与成交

每只股票有自己独立的买卖时点，不存在集中调仓。每个信号日按以下顺序：

1. **卖出**（当天收盘全部卖出，钱进现金）：
   - 信号转空 → 原因 `signal`；
   - 掉出前 N 家 → 原因 `pool`；
   - 同一公司的最大类别换了 → 原因 `class_switch`。
2. **类别切换：**卖出旧类别所得立刻全部买入新类别（原因 `class_switch`），前提是新类别信号为多；为空则留在现金。
3. **买入：**对象是前 N 家中、信号为多、当前未持有的公司（含本季新进入且信号为多的）。
   - 目标金额：`slot='equal'` 为总权益 × 1/N；`slot='amount'` 为总权益 × 该公司金额 ÷ 前 N 家金额之和。
   - 总权益 = 卖出之后的现金 + 全部持仓按当天收盘价计的市值。
   - 现金不足时全部买入按比例缩小，用完现金为止；现金不得为负。
4. **持有中的证券一律不调仓**：不拉回、不补仓、不减仓；股数只因公司行动变化。
5. **现金：**分红进现金、不再投资；主结果现金收益 0（`cash_rate='zero'`）；另跑一版按 3 个月国债计息（`cash_rate='dtb3'`，`api.rf_daily` 按日累计到现金）。
6. **公司行动与缺价：**沿用引擎在 `research_v1` 下的现有处理。

**版本切换：**新季度版本生效的信号日，先按新版本判断"掉出"和"新进入"，再按上述顺序处理。

## 6. 对照组

| 编号 | 对照 | 做法 |
|---|---|---|
| C1 | 一直持有 | 同池子、同名额、同"不调仓"，信号永远为多（`ma='always'`）；只因池子变动和类别切换交易。4 N × 2 名额 × 2 现金 = 16 次 |
| C2 | 相同平均仓位的固定配比 | 不跑回测。对每个趋势组合取平均仓位 e，用同 N、同名额 C1 的日收益构造 `r_mix = e × r_C1 + (1−e) × r_cash`；报年化、最大回撤及日期、2020/2022 年内最大回撤 |
| C3 | VOO 上的均线 | 对 `BENCH:VOO` 用同样 23 条规则：为多时全仓 VOO，为空时现金。2 现金口径，46 次 |
| C4 | 一直持有 VOO | 引擎基准 |

## 7. 规模

- 趋势：23 × 4 N × 2 名额 × 2 现金 = **368 次**
- C1：**16 次**
- C3：**46 次**
- 合计 430 次。

## 8. 每个组合报的数字

收益：年化、相对 VOO 年化超额、年化波动、年化 ÷ |最大回撤|、每个自然年收益（2014、2024 为不完整年）、最差自然年。

回撤：最大回撤及峰值/谷底/恢复日期、最长水下交易日、2020 年内与 2022 年内最大回撤。

仓位与交易：平均仓位（`average_invested_ratio`）、平均持有只数、最大单只权重、每年交易次数（按 `signal`/`pool`/`class_switch` 分开）、年单边换手。

每个趋势组合并列给出同 N、同名额、同现金的 C1 的同样数字，以及 C2 的年化、最大回撤、2020/2022 年内最大回撤。

## 9. 三段大跌

用 VOO 总回报在开发段内找出三段回撤，写明实际峰值、谷底、恢复日期：2018 年第四季度、2020 年 2–3 月、2022 年全年。

对每个趋势组合、C1、C3 报：该段内（VOO 峰到谷）的收益、VOO 谷到恢复的收益、该段内仓位最低值、仓位首次低于 50% 的日期及之后首次回到 50% 以上的日期。

## 10. 单只股票层面（不用引擎）

范围：开发段内曾进入前 20 家的全部公司，各信号日取最大类别；每只股票用它在 2014-02-28 至 2024-06-28 的完整历史，不受是否在池中限制。

对每只股票 × 23 条规则：

1. 规则交易（为多全仓、为空现金、零成本、现金 0 收益）与一直持有的年化、最大回撤、年化 ÷ |最大回撤|、平均在场比例、每年交易次数。
2. 每个信号日按当天信号分组的之后 1/4/13 周总回报：两组的平均值、样本数、两组之差；13 周窗口越过 2024-06-28 的样本不计。

汇总：每条规则上"规则年化 ÷ |最大回撤| 高于一直持有"的股票占比、"规则最大回撤小于一直持有"的股票占比、前向收益差的平均值与中位数。

## 11. 报告格式

只写数字，不写结论性评价，不设门槛，不因结果改网格。主表用"快线 × 慢线"方阵，每个（均线种类, N, 名额, 现金）一张，单元格写超额、最大回撤、平均仓位。
