## 2. 已确定的裁决

1. **主测试设定：**N=10、b=2、R2、细分行业上限 k=3；5bp 与 10bp 都跑。N=8/12 只在最终候选上做敏感性检查。
2. **比较方式：**每个机制只与事先指定的锚点配对比较，并使用它自己的随机对照（N=10、自己的退出节奏、与它相同的结构约束）。不存在统一的"先抵消 5 个百分点"门槛。
3. **90 日只是本样本中的锚点区域，不是规律。**不在 70、80、100、110 日附近微调。
4. **入场与出场分开：**新买入必须同时满足中期保留条件，防止"本周买入、下周被卖出"的旋转门；短期信息做一对正反对照（加分 vs 不追过热）。
5. **板块约束：**用冻结的 `config/sector_map_v1.csv`（11 个大板块）。每板块最多 3 只为主方案，2 只为对照，保留细分行业 k=3。行业不明的证券不合并成一个板块。金额约束暂不做。评价以集中度达标为第一标准，收益差只记为代价，由投资者决定是否接受。
6. **跳过最近 5 天：**只作一对证伪测试，固定最早观察日。
7. **按 VOO 权重排序的组合**作为同一引擎中的参照，不参与晋级。
8. **第一轮只决定机制是否晋级，不更换默认策略。**
9. **数据规则 v2**（见 3.1）通过：只改账本处理，基准结果必须逐字节不变。
10. **评分规则这一轮不放宽**（"窗口内部只缺一天仍可评分"留作以后的新数据版本）。

## 3. 开跑前的工程准备（不是策略试验，不计入试验次数）

### 3.1 数据规则 v2（账本规则；策略、锚点、随机对照、独立验收一律相同）

**规则 A：零碎股现金的通用近似**
- 适用：公司行动（分拆、拆股、反向拆股、股票股利）产生不足一股的权益，按事件性质应以现金结算，而补充数据版本中没有核实过的结算记录。
- 金额：零碎股数 × 被结算证券首个正常交易日的收盘价（分拆用子股，拆股类用事件后的该证券）。
- 时点：价格出现之前不得用它估值或计入预算，权益先记为应收证券；价格出现后转为现金应收，在事件生效交易日之后第 10 个交易日到账；不收手续费。
- 已核实的结算记录优先。已获批准的既有事件（GE、MMM、BBWI）结果必须不变。
- 每笔标记为近似，报告金额与占权益比例；超过 0.1% 的单独标红。
- 不得扩展到未知收购对价、未知退市回收或缺失整股权益。

**规则 B：持仓单日缺价**
- 适用：持仓证券在某个交易日没有价格，且当天没有公司行动。
- 估值：按前一交易日收盘价，标记 stale。
- 交易：当天不交易该证券；如果当天是执行日，该证券的买卖指令作废，不顺延，下一次每周检查按新信号重新判断；其余交易照常。
- 信号日缺价：该证券当周不可评分；已持有的不因此被判退出，当周保留并占用名额，不再触发"持有的合格证券不能评分"的停止。
- 连续第二个交易日仍无价：回到现有的停止规则。
- 新买入候选当天无价不能成交。

**闸门：**规则实施后，基准逐字节检查、small_check 回归、legacy 回归必须全部通过；第四阶段已审阅结果不得因此改变。任何改变都要停下查明。

### 3.2 随机对照修正

- 分组按配置 ID，不再按（N、b、R、信号）合并；每个配置的退出节奏取自它自己的探索档 10bp 运行。
- 随机组合遵守与被测配置相同的结构约束（细分行业 k、大板块上限）。
- 实验中每个新配置都生成随机对照（不只是前几名）。

### 3.3 登记与运行框架

- 登记文件的网格可以写入选股规则与参数；配置 ID 由信号、选股规则、参数、N、b、R 确定性生成；去重计数把选股规则纳入。
- 每个配置写明自己的锚点；成绩单报告与锚点的配对差、逐年剔除最小值、随机对照点估计与上下界，以及各机制专属指标（见 4.3）。

### 3.4 最小诊断

- **D3 修正：**权重与收益区间对齐（均取执行日收盘，收益为执行日收盘到下一执行日收盘），重算原 4 个配置并加上 N=10 的 L90 R2/R1。
- **D5 重跑：**在规则 v2 下重跑原 N=8 的 6 个窗口，确认停止基本消失；再为三个 N=10 锚点各跑 100 次随机对照。
- **D7 名次分段（L90 为主，L60、L126 附带）：**第 1–8、9–16、17–32 名、第 33 名到五分位末、第四五分位、最低五分位；4/8 周向后收益相对股票池的均值、中位数、正值周占比；再做板块中性化（减去同板块平均）；前 32 名内再按 VOO 权重三分位、60 日波动三分位切分。
- **D8 权重暴露：**A90 的新买入与持仓、以及 N=10 随机对照持仓，在 VOO 权重十分位上的分布。

## 4. 第一轮实验（R1_mechanisms，12 个新配置）

### 4.1 共同定义

- N=10、b=2、R2、k=3、5bp 与 10bp、开发段。
- U_L：当周合格、被类别选中、且 L 日动量可评分的证券。
- P_L：在 U_L 内的百分位。按（−分数, security_id）排序，名次 i 从 1 开始，n 为集合大小，P = (n−i)/(n−1)，n=1 时为 1。
- M_L = TRI(t)/TRI(t−L) − 1。
- 保留线：按该配置的持有分与全部容量约束生成可行顺序 F，取第 min(20, |F|) 名的排序键（与现有规则相同）。

### 4.3 评判标准（看结果之前登记）

**晋级下一轮**（ENT_POS、ENT_NEG、SKP90、SKP60、PEER、G、VOLA、SIZE），须同时满足：
1. 10bp 下相对锚点的年化超额差 ≥ +1.0 个百分点，5bp 下同向；
2. 两个时段（2019-11-29 至 2021-12-31、2022-01-01 至 2024-06-28）的配对差不出现方向相反；
3. 2020–2023 逐年剔除一年后，至少 3 次相对 VOO 的超额仍为正；
4. 自己的随机对照百分位下界 ≥ 75%。

另外：
- SKP90 与 SKP60 必须同向改善，才支持"跳过最近 5 天"这一机制；只把 L60 "亏得少一些"不算晋级。
- ENT_POS 与 ENT_NEG 的方向比较本身就是结论：说明短期信息在入场时该加分还是该回避。
- G 与 PEER 用于归因：G 明显变弱而 PEER 不弱，支持"板块整体涨幅"是 L90 优势的来源。

**SEC3、SEC2：**集中度达标为第一判据：单一大板块超过 50% 的天数 ≤ 5%，超过 40% 的天数至少减半。报告最大板块权重的中位数、90 分位、最大值，以及收益代价；收益不作为否决条件。SEC3 达标时优先采用较宽松的 SEC3。

**CAP2：**年换手至少下降 15%，且 10bp 超额下降不超过 0.5 个百分点；报告触发周数与顺延次数，几乎不触发时不作判断。

**WGT：**只作参照。A90 不优于 WGT，说明趋势信号没有超过"买大公司"。

**成为新默认：**需要在下一轮独立复现，随机对照下界 ≥ 90%。如果是从多个机制中挑最好的，还要做实验级随机对照（在每个随机种子内重复同样的挑选过程）。

**必须报告**（所有配置）：两种成本、逐年、两个时段、逐年剔除最小值、随机对照的点估计、上下界与完成数、实际换手与随机换手、最大单股权重、单一板块超过 40%/50% 的天数、ENT 的两遍买入数、CAP 的触发与顺延次数。

## 6. 已知局限与提醒

- 开发段只有约 4.6 年、一段市场环境；所有结论都是这段样本内的。
- 幸存者偏差：缺价成员占 VOO 权重 4.5%（2019 年）到 1.3%（2024 年），方向不确定。
- 行业分类是今天的富途分类；大板块层面的结论可信度中等，细分行业层面低。
- **与投资者目标的冲突：**本样本中追短期强势吃亏。第一轮的入场设计都要求新买入在中期已经够强，抓不到中期还很弱的底部初起。只有板块同伴与以后的板块广度方向，有可能更早发现板块启动。若实验确认这一点，需要由投资者在"更早入场"与"实际收益"之间取舍。

### 7.1 收益与判定（10bp，相对 VOO 年化超额；A90 为 +2.6%）

### 7.3 解读

- 所有为"灵活、捕捉启动"设计的机制（ENT_POS、ENT_NEG、SKP、PEER）都失败了；PEER 还造成极端集中。

  - 高度依赖 NVDA：它占 A90 总盈亏的 42%、SIZE 的 40%。剔除 NVDA 后，A90 为 −4.1%，SIZE 为 +0.7%；两边都剔除后，SIZE 仍比 A90 高 4.8 个百分点，G 高 5.6 个百分点。SEC3 尚未做这项测试。

### 8.2 稳健性检验（不计入试验次数，不用于挑选配置）

1. **噪音尺（起点推迟）：**对 A90、WGT、SEC3、SIZE、G（第一轮）以及 C_SEC3_SIZE、C_SEC3_G，把开发段的起始信号周分别推迟 1、2、3、4 周，结束日不变，10bp 探索档。报告每个起点下的超额、相对各自锚点的配对差（锚点用同一起点），以及 5 个起点（含原起点）的均值、最小值、最大值。
2. **剔除 NVDA：**对同一组 7 个配置，把发行人 LEI:549300S4KLFTLO7GSQ80（NVIDIA）的全部证券类别从每周股票池中整体剔除后重跑，5bp 与 10bp 探索档。报告剔除前后的超额，以及两边都剔除后相对锚点的配对差；同时列出每个配置自己的头号贡献发行人。
3. **实验级随机对照：**与第一轮相同的方法，在第二轮的 12 个配置上计算。

### 8.3 评判标准（看结果之前登记）

**组合（C_SEC3_SIZE、C_SEC3_G），相对 SEC3：**
1. 10bp 配对差 ≥ +1.0 个百分点，5bp 同向；
2. 两个时段的配对差不出现方向相反；
3. 2020–2023 逐年剔除一年后，至少 3 次相对 VOO 的超额为正；
4. 自己的随机对照百分位 ≥ 75%；
5. 噪音条件：推迟 1–4 周的 4 个起点下，配对差的平均值 ≥ +1.0 个百分点，且至少 3 个为正。

**复现（SIZE、G、SEC 各在 L126、N=8、N=12 三个设定中）：**
- 一个机制在 3 个设定中至少 2 个的 10bp 配对差为正，且没有一个低于 −2.0 个百分点，才算复现成功；
- SEC 类在每个设定中还须满足：单一大板块超过 50% 的天数 ≤ 5%。

**SEC4：**与 SEC2、SEC3、A90（相当于不设上限）一起，报告板块上限 2/3/4/不设上限的收益与集中度曲线。不单独判定。

**剔除 NVDA：**两边都剔除后配对差仍为正，算作支持机制本身有效；只作判断依据之一，不单独否决。

**必须报告（不作门槛）：**年化波动、β、跟踪误差、收益/波动、收益/回撤、最大回撤、2022 年内的最大回撤、最大单股权重、单一大板块超过 40%/50% 的天数，以及与 WGT 的配对差。

### 8.4 第二轮不做的

- ENT、SKP、VOLA、PEER、CAP2 的任何变体：第一轮已失败，且离门槛不近；
- SIZE 的力度调整、窗口微调：围绕赢家微调；
- 板块金额约束：SEC3 的单一板块最大权重为 40.3%，已经达标；
